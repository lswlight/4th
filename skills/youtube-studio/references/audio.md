# 소리 마무리 — 이음 잡음('찍', '뻑', '틱') 막기

내레이션·현장 소리를 이어 붙인 영상은 이음매에서 잡음이 나기 쉽다. 아래 다섯 가지를 **항상** 지킨다.
(2026-11-23 사용자 요청. 대마도 마운자로 2·3편에서 실제로 겪은 문제를 바탕으로 정리.)

## 왜 생기나

| 소리 | 원인 |
|---|---|
| 문장 앞뒤 '틱/칙' | AI 음성(예: Higgsfield seed_audio)이 말 앞뒤에 20~40ms짜리 잡음 덩어리를 붙여 낸다 |
| 말끝 '뻑' + 뚝 끊김 | 말소리가 아직 남아 있는데 잘랐다 (말끝 여운을 잘라 먹음) |
| 이음매 '찍' | 두 소리를 맞대어 붙여 파형이 튄다 |
| 미세한 '틱' | 장면마다 AAC로 압축한 뒤 이어 붙였다 |
| 지지직, 찢어짐 | 음량을 올려 최대값이 0dB 근처까지 갔다 |

## 다섯 가지 규칙

1. **AI 내레이션은 한 문장씩 정리한다** — 앞뒤의 짧은 잡음 덩어리(80ms 이하, 말소리와 0.2초 이상 떨어진 것)만 지우고, 말끝은 소리가 −60dB 아래로 내려갈 때까지 살린 뒤 80ms 페이드.
   `python3 scripts/audioqc.py clean 원본.wav 정리.wav --pad 0.3`
2. **모든 이음매에 짧은 페이드** — 무음 간격을 두고 붙일 때는 조각 앞뒤 30ms 페이드. 같은 현장 소리를 중간에서 자를 때는 0.03~0.08초 크로스페이드.
   `python3 scripts/audioqc.py join a.wav b.wav -o 합본.wav --gap 0.3` / `--xfade 0.05`
3. **압축은 마지막에 한 번만** — 조각은 WAV(PCM)로 이어 붙이고, 최종 영상을 만들 때 AAC로 한 번만 압축한다. 장면별 mp4를 `-c copy` 로 이어 붙이지 않는다.
4. **마지막에 잡음 제거 필터** — 최종 인코딩의 오디오 필터 끝에 `adeclick` 을, 맨 끝에 리미터를 둔다.
   `-af "adeclick,alimiter=limit=0.9:level=disabled"` (최대 음량 약 −1dB 이하로 묶여 찢어지지 않음)
5. **완성본을 자동 점검하고, 걸린 시각만 귀로 확인한다**
   `python3 scripts/audioqc.py check 완성본.mp4`
   - 갑자기 끊김이 1곳이라도 있으면 그 장면을 다시 만든다.
   - 튀는 소리는 말하는 중간의 ㅊ·ㅋ·ㅌ 자음도 잡히므로, 잡힌 시각을 사용자에게 알리고 직접 들어 본다.

## 그래도 안 될 때

- AI 음성이 특정 단어를 계속 이상하게 읽으면(예: '춥지'→'취지') 발음대로 적어 다시 만들거나(`춥찌 안코`), **사용자가 직접 녹음한 한 줄**로 바꾸는 게 가장 깔끔하다.
- 사람이 직접 편집할 때: 무료는 Audacity '클릭 제거', DaVinci Resolve(Fairlight) 페이드, CapCut 페이드 인/아웃. 유료는 iZotope RX 'De-click', Adobe Audition 'DeClicker'. 가장 간단하고 확실한 건 **이음매마다 짧은 페이드**.

# 제목·썸네일 (원본: yt-package)

제목과 썸네일은 **한 단위**다. 따로 쓰면 썸네일이 제목을 반복해서 클릭 화면의 절반이 같은 말을 두 번 한다.

```bash
python3 scripts/title.py --title "…" --thumb "…"
python3 scripts/title.py titles.txt --thumb "…"     # 여러 제목을 같은 썸네일과 맞춰 순위
```

## 도구가 보는 규칙

- **길이**: 유튜브는 화면 폭으로 자른다. 데스크톱 검색은 한글 약 35자, 모바일 홈 피드는 약 23자에서 잘린다. 모바일에서 잘려도 **주제어가 앞쪽에 살아남는지** 본다.
- **썸네일은 제목을 반복하지 않는다.** 다른 단어로 같은 약속.
- **썸네일 문구는 3어절·12자 안쪽.** 피드 크기에서 넷째 어절은 회색 얼룩이 된다.
- **숫자·이름·날짜**가 어떤 형용사보다 낫다. '대박·역대급·꿀팁·충격'은 감점.
- 영어 전부 대문자 단어는 둘까지 (ETF, FOMC, NVDA 같은 약어는 예외).

## 열 개 쓰고 둘 남긴다

1. 제목 후보 열 개를 쓰고 `title.py` 로 모두 돌린다.
2. 상위 셋을 점수와 문제점과 함께 보여 준다.
3. `vidiq_score_title` 은 기본으로 쓰지 않는다 (제목 하나에 5크레딧). 사용자가 "vidIQ로도 점수 봐줘"라고 할 때만 1위 제목 하나에.
4. 1위 제목에 맞춰 **썸네일 기획**을 쓴다: 표정·인물 유무, 구도, 문구 3어절, 피드 크기에서 대비를 지키려면 배경이 어떻게 해야 하는지. 투자 영상이면 차트를 어떻게 넣을지(전체 차트가 아니라 돌파 지점 하나 확대 등).

## 투자 콘텐츠

"무조건", "100% 오른다", "지금 안 사면 늦는다" 같은 단정·권유를 제목·썸네일에 쓰지 않는다. 질문형이나 조건형("상단 돌파, 진짜일까?")으로 쓴다.

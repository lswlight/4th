# 바이럴 찾기 (원본: yt-viral, 수집은 vidIQ로 대체)

조회수 순위는 채널 크기 순위다. 아이디어를 보려면 **그 채널 평소 조회수 대비 몇 배 나왔는지**로 봐야 한다.
구독자 200만 채널의 40만 조회는 평범한 화요일이고, 평소 3만인 채널의 40만은 연구할 대상이다.

## 찾기

**vidIQ `vidiq_outliers`** 가 이 배수(breakout score)를 이미 계산해 준다.
- `keyword`: 주제 (한국어 그대로), `language: "ko"`
- `contentType`: `"short"` 또는 `"long"`
- 특정 경쟁 채널이면 `channelIds`, 특정 영상과 비슷한 것이면 `seedVideoId`
- `publishedWithin` 은 사용자가 기간을 말할 때만
- 복붙 채널을 거르려면 `minEngagementRate: 0.02` 정도

vidIQ가 없으면 사용자에게 채널별 영상 목록(채널, 제목, 조회수)을 받아 채널마다 중앙값을 내고 배수를 계산한다. 채널당 영상이 **4개 미만이면 중앙값이 의미 없으니** 빼고 그렇다고 말한다.

## 읽기

1. 상위 다섯 개를 배수와 함께.
2. 각 제목이 `scripts/hooks.json` 21가지 공식 중 어디에 해당하는지 (`hookscore.py --json` 에 제목을 넣으면 `formula` 가 나온다). **이건 보이는 제목 단어에 대한 판단이지, 영상이 왜 떴는지에 대한 주장이 아니다** — 그렇게 말하고 전한다.
3. 다섯 개가 공유하는 **구조적 공통점 하나**.
4. 더 어려운 줄: 이 중 사용자가 **이번 주에, 자기 말투로, 가진 것으로** 실제 만들 수 있는 게 무엇인지.

## 더 깊이 보려면

상위 영상의 장면·편집·대본까지 뜯어봐야 하면 그 링크를 **youtube-analyzer** 로 넘긴다 (Gemini가 영상을 직접 본다). 여기서 같은 분석을 하지 않는다.

**읽기만 하고 긁어 오지 않는다.** 공개 목록만. 사용자 계정으로 로그인하거나 자격 증명을 쓰지 않는다.

# 편집·쇼츠 (원본: yt-edit, yt-shorts)

## A. 컷 편집 목록

```bash
python3 scripts/deadair.py transcript.srt              # srt, vtt, whisper json
python3 scripts/deadair.py transcript.srt --floor 0.35 --json
```

자막이 없으면 먼저 받는다: 유튜브에 '일부 공개'로 올린 뒤 자동 자막을 받거나, whisper / faster-whisper로 만든다. **타이밍을 추측하지 않는다.**

| 표시 | 뜻 | 자르는 방법 |
|---|---|---|
| DEAD | 기준보다 긴 공백 | 가운데만 자른다. 말에 딱 붙여 자르면 숨 막히게 들린다 |
| FILLER | "음", "어", "그러니까", "막" 만 있는 자막 | 통째로 |
| REPEAT | 같은 문장을 다시 시작 (NG) | 앞 테이크를 자른다 |

**하지 않는 것**: 파일을 자르지 않는다. B-roll은 판단하지 않는다. 결과의 "몇 % 짧아짐"은 **말 기준**이라, 말없이 차트만 보여 주는 구간이 길면 실제와 다르다. 영상과 대조하라고 말한다.

## B. 긴 영상 속 쇼츠 찾기

긴 영상에서 잘라 낸 쇼츠는 '가장 좋은 순간'이 아니라 **앞뒤 없이도 살아남는 순간**이다. 그런 구간은 훨씬 적다.

자막에서 20~55초 구간 중 세 가지를 모두 만족하는 곳을 찾는다.
1. 완결된 생각으로 시작한다. 첫 문장이 앞 1분을 알아야 이해되면 쇼츠가 아니다.
2. 안에 꺾임이 있다. 주장 → 그걸 뒤집거나 증명하는 것.
3. 말끝이 흐려지지 않고 한 문장으로 끝난다.

후보를 순위대로 다섯 개, 타임코드와 첫 문장을 함께 보여 준다 (사용자가 자막 전체를 읽지 않고 고를 수 있게).

각 쇼츠마다:
- **새 첫 문장**: 원래 문장은 맥락을 전제한다. 바꿔 쓰고 `hookscore.py` 로 돌린다.
- **첫 2초 화면 문구**: 말과 다른 단어로.
- **루프 지점**: 마지막 문장이 첫 문장으로 이어지게.
- **세로 화면 메모**: 16:9에서 9:16으로 자를 때 잘려 나가는 것 (차트 오른쪽 가격축 등)과 그게 문제인지.

실제 클립 파일이 필요하면 vidIQ `vidiq_generate_clips` 를 쓸 수 있지만 **분당 크레딧**이 든다. 사용자가 허락할 때만, 고른 구간만 `processingStartSeconds/EndSeconds` 로 지정한다.

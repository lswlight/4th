# 슬라이드 영상 제작 틀 (칭다오 마운자로 1·2편에서 만든 것)

조사한 내용을 **슬라이드(PDF) → 녹음 → 모션그래픽 영상**으로 만드는 틀이다.
새 영상을 만들 때 이 폴더를 작업 폴더(`media/<편>/`)로 복사해서 쓴다.
`media/` 는 저장소에 올라가지 않는다. 녹음, 블로그 캡처, 개인정보는 거기에만 둔다.

## 진행 순서 (사용자와 맞춘 방식)

1. **자료 조사**: 블로그 후기와 검색 결과를 읽고 사실만 모은다.
2. **슬라이드 PDF**와 **나레이션 원고(narration.txt)**를 먼저 보여 준다.
   - 화면에는 큰 글자만 넣는다. 자세한 설명은 나레이션으로 뺀다.
3. 피드백을 받아 고친다.
4. 사용자가 **직접 녹음**한 파일을 받는다. 여러 개로 나눠 녹음하고, 버벅인 부분은 다음 파일에서 다시 녹음하는 방식이다.
5. 받아쓰기로 문장을 슬라이드에 맞춘다.
   - 같은 문장이 두 번이면 다시 녹음한 쪽을 쓴다.
   - 3~5초 쉰 곳은 0.5초 안팎으로 줄인다.
6. 영상을 만든다(모션그래픽, 자막, 마지막 장 면책 문구).
7. 업로드용 설명·제목·태그와 썸네일을 만든다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `_head.py` | 글꼴·색, 카드, 번호 원, 화살표, 휴대폰 예시 화면(`Phone`), 콜아웃(`callouts`), 기본 남색 배경. `W, H, N`(장 수)과 `FOOT`(오른쪽 위 작은 글씨)를 편마다 고친다. |
| `_helpers.py` | 실사 배경 프레임 `frame(n, step, label, title)`, 도현체 외곽선 제목, 플랫 심볼 `sym()`, 사진 카드 `photo()`, 실제 화면 캡처와 노란 표시(`shot`, `mark`), 큰 콜아웃(`big_callouts`), 위챗 대화 예시(`wechat`), 표지용 `tag`·`otext`. |
| `example_build_deck.py` | 2편(징동 주문) 슬라이드 13장 전체 코드. 새 편은 이 파일을 복사해 장마다 고친다. 맨 끝에 PDF를 저장한다. |
| `mg.py` | 모션그래픽. 장마다 배경과 제목(`slides_bg/`)을 먼저 깔고, 요소 사각형을 정한 시각에 아래에서 떠오르게 한다. `EMPH` 로 말하는 카드를 1.07배 키울 수 있다. |
| `example_make_video.py` | 2편 영상 코드. 아래 "영상 만들기"에 자세히 적었다. |
| `stt.py` | 무료 받아쓰기(faster-whisper small, 문장·단어 시각). 사용법: `python3 stt.py rec/j1.m4a rec/stt_j1.json` |
| `fetch_photos.py` | Unsplash 무료 사진 검색·다운로드, 미리보기 `sheet.jpg`, 출처 `credits.txt`. |
| `get_fonts.sh` | Noto Sans KR 500/700/900과 도현체를 `~/.cache/slide-video/fonts` 에 받는다. |

### 영상 만들기 (`example_make_video.py`)

- **`CLIPS`**: 슬라이드 번호마다 녹음 구간 `(파일, 시작, 끝, 뒤 쉼)` 목록이다. 여기서 버벅인 곳을 빼고, 다시 녹음한 곳을 고른다.
- **`cue()`**: 받아쓰기 단어 시각으로 요소 등장 시점을 잡는다. 말할 때 카드가 나타나는 방식이다.
- **`FIX`**: 받아쓰기 오타를 바로잡은 자막이다.
- 자막만 바꿀 때는 `SUBS_ONLY=1 python3 make_video.py` 로 다시 합치기만 한다.

## 준비

```bash
bash get_fonts.sh                       # 글꼴 (한 번만)
pip list | grep -i faster-whisper       # 없으면: pip install faster-whisper
mkdir -p media/<편> && cp templates/slide-video/* media/<편>/
mv media/<편>/example_build_deck.py media/<편>/build_deck.py
mv media/<편>/example_make_video.py media/<편>/make_video.py
```

- 중국어(간체)는 시스템 글꼴 wqy-zenhei로 자동으로 바뀐다. 없으면 `apt-get install fonts-wqy-zenhei` 로 설치한다.
- 도현체에는 "·" 글자가 없다. 도현체로 쓰는 제목과 표지에는 "|" 를 쓴다(`frame` 제목은 자동으로 바뀐다).

**사진 넣는 곳 (`src/`)**

| 위치 | 용도 |
|---|---|
| `src/bgq/k{n}.jpg` | 장마다 배경. 편마다 다른 사진을 쓴다(1편 낮 바다, 2편 야경). |
| `src/us/*.jpg` | 카드 사진 |
| `src/box_cut.png` | 제품 상자 누끼(선택) |

- 배경은 `fetch_photos.py src/bg "qingdao night" ...` 로 받아 `sheet.jpg` 를 보고 고른다.
- 배경 사진이 없으면 남색 그라데이션이 깔린다.

## 디자인 규칙 (사용자 피드백으로 정한 것)

- **표지는 썸네일처럼 만든다.**
  - 실사 배경 사진(왼쪽을 어둡게)
  - 초록 시리즈 태그(편 번호는 노랑), 빨간 부제 태그
  - 도현체 큰 세 줄(노랑, 강조색, 하늘색)
  - 오른쪽에 기울인 예시 화면과 사진 카드
- **AI 그림 같은 일러스트와 대충 만든 아이콘은 싫어한다.**
  - 카드에는 **실제 사진**(Unsplash)을 쓴다.
  - 작은 표시(✕, ✓, 경고)만 플랫 심볼로 쓴다.
- **휴대폰 화면은 예시 그림**이다. 장 아래에 "※ 이해를 돕는 예시 화면 · 실제 앱과 다를 수 있음"을 넣는다.
- **한자만 있는 콜아웃은 안 된다.** 한국어 설명을 먼저 쓴다(예: "신분증 변경: 身份证 → 外籍护照").
- **마지막 장**에는 "직접 경험이 아닌, 여러 후기를 조사해 정리한 내용입니다"와 의학·투자 면책을 넣는다. 영상에서는 위쪽 Note 자막으로 한 번 더 띄운다.
- **출력 영상**은 `-pix_fmt yuv420p -profile:v high` 로 만든다. yuv444로 만들면 휴대폰에서 재생이 안 된다.

## 반드시 지킬 것

- **유료 생성 크레딧(힉스필드 등)은 쓰지 않는다.** 쓸 일이 생기면 먼저 묻는다.
- **조사 내용은 지어내지 않는다.**
  - 사용자가 경험하지 않은 비용이나 결과를 경험담처럼 쓰지 않는다.
  - 근거가 약한 내용은 빼거나 "후기 기준"이라고 적는다.
- **의료 내용**
  - 처방은 "사실대로 답하기"로만 안내한다.
  - 다른 질환명을 고르라거나 임의 번호를 넣으라는 요령은 넣지 않는다.
  - 용량은 "의사와 상의"라고 쓴다.
- 업로드는 하지 않는다. 결과물은 복사·붙여넣기용이다.
- 사진 출처(Unsplash 작가·링크, Wikimedia 라이선스)는 설명란에 적는다.
